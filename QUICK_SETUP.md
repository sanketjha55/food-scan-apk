## Step 1: Create Repo Manually
```
https://github.com/new खोलो

```

## Step 2: Run This Command
```powershell
cd d:\ntcc
git remote remove origin 2>$null
git remote add origin https://github.com/sanketjha55/food-scanner-app.git
git branch -M main
git push -u origin main
```

## Step 3: Wait for Build
```
Go to: https://github.com/sanketjha55/food-scanner-app/actions
Wait for green ✅ (15 minutes)
```

## Step 4: Download APK
```
https://github.com/sanketjha55/food-scanner-app/releases
Download: app-release.apk ✅
```
